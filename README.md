# 🧉 Repartija - Cuentas claras, mates compartidos

¡Bienvenido a **Repartija**! La app definitiva para que no te vuelvan a cagar con los gastos del asado, el alquiler o las vacaciones con amigos. Olvidate de andar anotando en un papelito o mandando audios de 5 minutos explicando quién puso la plata.

## 🚀 ¿Qué onda con esta app?

Repartija es una aplicación de Android pensada para gente que comparte gastos y no quiere quilombos. Usamos **Supabase** para que todo se sincronice al toque y **Firebase** para que te llegue el "chiflido" (notificación) apenas alguien agrega o modifica algo.

### ✨ Características principales:
*   **Grupos a medida**: Armá grupos para lo que quieras (el depto, el equipo de fútbol, el asado, viaje a Bariloche).
*   **Sincronización en tiempo real**: Si tu amigo carga una pizza, te aparece en la pantalla antes de que termine de morder la primera porción.
*   **Notificaciones Push**: "Movimiento modificado en [Grupo]". Enterate al toque quién puso qué.
*   **Gráficos de deuda**: Mirá cómo viene tu historial con cada miembro. ¿Te están debiendo más de la cuenta? El gráfico no miente.
*   **Multipayadores**: Porque a veces uno pone la carne y otro la bebida. Soportamos pagos divididos y múltiples pagadores por gasto.
*   **Diseño Premium**: Fondo personalizado con iconitos bien nuestros (el mate, el asadito, el carrito) y una interfaz que es un amor.

## 🛠️ Stack Tecnológico
*   **Lenguaje**: Kotlin (Jetpack Compose para la UI, bien moderno).
*   **Backend**: Supabase (PostgreSQL + Realtime + Edge Functions).
*   **Notificaciones**: Firebase Cloud Messaging (FCM).
*   **Inyección de dependencias**: Hilt (para que el código sea prolijito).
